# FND-003 — Container packaging and release automation

**Status:** Done  
**Authority:** `openspec/changes/bootstrap-mq-mcp/proposal.md` ·
[ADR-0009](../../docs/adr/0009-license-and-oss-maturity.md)

## Outcome

Tagged releases produce the approved CGO-free artifacts (binary and/or
hardened container) with SBOM, provenance, cosign signatures, and release
notes, without manual steps — following the Kollect/MKurator release pattern.

## Acceptance

- Container (if mandatory) runs nonroot with a read-only filesystem and
  appropriate health handling for its transports.
- Releases attach SBOM and provenance; generation failure fails the release
  (no silent omission).
- Images/binaries are cosign-signed (keyless OIDC) like Kollect/MKurator.
- Versioning and release notes are automated from a documented convention.
- Reproducible CGO-free builds are verified in CI.
- License is MIT (ADR-0009); mandatory artifact set is recorded before first tag.
