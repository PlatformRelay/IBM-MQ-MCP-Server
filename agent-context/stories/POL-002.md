# POL-002 — Object-name allow/deny constraints

**Status:** Blocked by ADR-0003  
**Authority:** `openspec/changes/connection-profiles-and-policy/proposal.md`

## Outcome

A profile can restrict granted capabilities to allow/deny object-name patterns
evaluated together with the capability decision, before any adapter call.

## Acceptance

- Matching is deterministic and documented; deny wins over allow.
- Constraint denial is distinguishable from capability denial in errors and
  audit events.
- Default handling of `SYSTEM.*` objects is explicit and tested.
- Tests cover overlapping patterns, case rules, and empty constraint sets.
- Denied operations provably make no downstream call.
