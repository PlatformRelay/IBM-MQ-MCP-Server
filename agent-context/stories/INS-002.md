# INS-002 — Inspect channels, listeners, and subscriptions

**Status:** Open; depends on INS-001  
**Authority:** `openspec/changes/typed-inspection-and-output/proposal.md`

## Outcome

Models inspect channel, listener, and subscription definitions and runtime
status through the same typed, bounded contract established by INS-001.

## Acceptance

- Typed list/get/status tools reuse the shared collection contract (filters,
  limits, cursors, truncation metadata) without divergence.
- Stale or unavailable status is distinguished from configured definitions.
- An object family unsupported by the connected mqweb deployment mode returns
  an explicit typed "unsupported" error, never an empty success.
- Reason codes map to actionable typed errors; platform differences are
  documented.
