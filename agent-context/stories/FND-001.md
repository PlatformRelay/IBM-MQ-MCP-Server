# FND-001 — Establish the Go module skeleton and minimal MCP server

**Status:** Open; ready to implement  
**Authority:** `openspec/changes/bootstrap-mq-mcp/proposal.md`

## Outcome

A contributor can build, test, and run a minimal MCP server from a clean
checkout using documented commands, inside the approved package boundaries.

## Acceptance

- Project layout enforces the ADR-0001 boundaries: `cmd/`,
  `internal/mcpserver/`, `internal/application/`, `internal/policy/`,
  `internal/mqadmin/`, `internal/messaging/`, `internal/adapter/`.
- Go and MCP SDK versions are pinned; the build is CGO-free.
- A minimal server passes protocol/SDK tests over the approved transports and
  registers no MQ tools yet.
- `go build`, `go test`, and the run command work from a clean checkout and
  are documented in AGENTS.md.
- No boundary package imports an outer layer, enforced by a lint or test.

## Decisions and open questions

- [ADR-0001](../../docs/adr/0001-go-and-official-mcp-sdk.md) selects Go and
  the official MCP Go SDK.
- [ADR-0009](../../docs/adr/0009-license-and-oss-maturity.md) locks MIT + OSS
  baseline; CI quality gates remain [FND-002](FND-002.md).
- CI gates moved to [FND-002](FND-002.md); packaging and release moved to
  [FND-003](FND-003.md); live MQ environment moved to [FND-004](FND-004.md).
