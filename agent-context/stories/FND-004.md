# FND-004 — Live IBM MQ development and e2e environment

**Status:** Done  
**Authority:** `openspec/changes/bootstrap-mq-mcp/proposal.md`

## Outcome

A contributor starts a disposable local IBM MQ with mqweb enabled and runs
tagged end-to-end tests against it using documented commands.

## Acceptance

- One documented command provisions a queue manager with mqweb, TLS, and test
  users; fixtures contain no real credentials.
- The environment exercises both Administrative and Messaging REST endpoints.
- e2e tests are tagged and skip cleanly when the environment is absent.
- Teardown leaves no persistent state.
- The MQ container licensing approach for local use and CI is documented.

## Open decisions

- ~~IBM MQ container licensing and version matrix for CI.~~ **Decided** — IBM MQ
  Advanced for Developers via `LICENSE=accept` / Helm `license: accept`; local
  and CI non-production only. Recorded in `decisions.md` and
  `docs/development/local-mq.md`.
