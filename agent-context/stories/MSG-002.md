# MSG-002 — Validated message production

**Status:** Blocked by message-safety decisions  
**Authority:** `openspec/changes/safe-messaging/proposal.md`

## Outcome

Profiles granted `produce` put messages with validated content types and
server-enforced size limits, and receive verifiable identifiers.

## Acceptance

- Put requires the `produce` capability; a denied put makes no MQ call.
- Accepted content types follow the approved decision (design question 17);
  anything else is rejected locally with a typed error.
- Payload size limits are enforced before any network call.
- Results return message and correlation identifiers and never echo the full
  payload by default.
- Payloads never appear in logs; e2e proves the message arrives with the
  declared format.
