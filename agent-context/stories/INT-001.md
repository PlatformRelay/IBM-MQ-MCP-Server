# INT-001 — Coexist with MKurator

**Status:** Blocked by ADR-0007  
**Authority:** `openspec/changes/mkurator-coexistence/proposal.md`

## Outcome

The server remains useful for generic IBM MQ while helping clients avoid
imperative changes that conflict with MKurator reconciliation.

## Acceptance

- No Kubernetes dependency is required for generic MQ operation.
- When enabled, ownership lookup maps an MQ object to a specific MKurator
  resource with freshness and source information.
- The approved warn, block, or declarative-handoff policy is enforced before
  direct mutation through a hook consumed by ADM-001/ADM-002.
- MKurator absence, insufficient Kubernetes permission, and stale resources
  degrade explicitly without weakening MQ policy.
- Integration uses published MKurator APIs rather than importing controller
  internals.
