# ADM-001 — Typed queue administration

**Status:** Blocked by administration scope  
**Authority:** `openspec/changes/guarded-administration/proposal.md`

## Outcome

Profiles granted `administer` create, alter, and delete queues through typed,
bounded operations that can coexist with declarative management.

## Acceptance

- Queue define/alter/delete use validated domain types; no raw MQSC crosses
  the port boundary.
- Destructive calls have clear tool annotations, explicit target identity,
  and auditable outcomes.
- Dry-run is exposed only where the server can truthfully validate/preview.
- MKurator-managed targets follow the approved warn/block/handoff behavior
  via the INT-001 hook.
- Contract and live tests cover idempotency, not-found, conflict, authority
  failure, and partial failure.
- Other object families are [ADM-002](ADM-002.md); raw MQSC policy is
  [ADM-003](ADM-003.md).
