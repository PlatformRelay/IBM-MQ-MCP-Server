# OUT-001 — Produce token-conscious structured results

**Status:** Open  
**Authority:** `openspec/changes/typed-inspection-and-output/proposal.md`

## Outcome

Tool results are schema-valid, concise, bounded, and measurably efficient for
supported clients and models.

## Acceptance

- Every public tool has an output schema and conforming `structuredContent`.
- Text compatibility rendering is deterministic and avoids redundant prose.
- Collection tools support field selection, filtering, pagination, and
  truncation metadata via the INS-001 shared contract.
- Representative MQ datasets benchmark compact JSON, Markdown tables, and TOON
  where applicable for tokens, correctness, latency, and client compatibility.
- A non-JSON rendering is adopted only with documented evidence and graceful
  fallback.
