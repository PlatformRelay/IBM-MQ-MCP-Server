# INS-001 — Inspect profiles, queue managers, and queues

**Status:** Open  
**Authority:** `openspec/changes/typed-inspection-and-output/proposal.md`

## Outcome

Models discover profiles and connection health and inspect queues and queue
status through typed, bounded tools without arbitrary MQSC — establishing the
collection contract every later tool reuses.

## Acceptance

- Typed tools cover profile listing with capabilities, queue-manager health,
  queue list/get, and queue status/depth.
- The shared collection contract (filters, stable limits, cursors, truncation
  metadata) is defined once here and documented for reuse.
- Results distinguish configured identity, observed identity, and stale or
  unavailable state.
- IBM MQ reason codes map to actionable typed errors.
- Unit and adapter tests cover distributed MQ; platform-specific differences
  are explicit.
- Channels/listeners/subscriptions are [INS-002](INS-002.md); diagnostics are
  [INS-003](INS-003.md).
