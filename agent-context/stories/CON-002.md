# CON-002 — Additional secret providers

**Status:** Blocked by ADR-0004  
**Authority:** `openspec/changes/connection-profiles-and-policy/proposal.md`

## Outcome

Profiles resolve credentials from Kubernetes Secrets and one approved external
provider through the same secret-reference grammar as env/file references.

## Acceptance

- Provider selection is driven by the secret-reference scheme; unknown schemes
  fail startup validation with an actionable error.
- A missing or forbidden secret at resolution time yields a typed, non-secret
  error and does not affect other profiles.
- Contract tests cover each provider; no secret value ever appears in logs,
  errors, or results.
- Providers are optional at build/run time; absence does not break env/file
  profiles.
