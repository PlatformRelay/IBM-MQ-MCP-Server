# ADM-003 — Raw MQSC exceptional gate

**Status:** Blocked by ADR-0008  
**Authority:** `openspec/changes/guarded-administration/proposal.md`

## Outcome

Raw MQSC is absent by default; if ADR-0008 approves an exceptional gate, it is
doubly opted in, parsed, allowlisted, and fully audited.

## Acceptance

- No raw MQSC tool is registered unless both server-level enablement and the
  profile's `execute_mqsc` capability are present.
- If allowlisting is approved, commands are parsed and verbs validated before
  any network call; denied verbs never reach MQ.
- Every execution is audited per the ADR-0008 command-text policy without
  leaking secrets.
- Tests prove the tool is undiscoverable and unexecutable in the default
  configuration.
