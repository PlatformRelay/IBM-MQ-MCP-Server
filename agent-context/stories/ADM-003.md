# ADM-003 — Raw MQSC exceptional gate

**Status:** Done (ADR-0008 accepted; lane/adm-003)  
**Authority:** `openspec/changes/guarded-administration/proposal.md`

## Outcome

Raw MQSC is absent by default; the exceptional gate is doubly opted in, parsed,
allowlisted, and audited per ADR-0008.

## Acceptance

- No raw MQSC tool is registered unless server-level `--enable-mqsc` (or env) is set.
- Profile `execute_mqsc` capability is required at call time.
- Commands are parsed and verbs validated before any network call; denied verbs never reach MQ.
- Every execution is audited with redacted command text.
- Tests prove the tool is undiscoverable and unexecutable in the default configuration.
