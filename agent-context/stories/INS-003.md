# INS-003 — Reason-code and connectivity diagnostics

**Status:** Open; depends on CON-001  
**Authority:** `openspec/changes/typed-inspection-and-output/proposal.md`

## Outcome

Models translate IBM MQ reason codes into explanations and next actions, and
verify a profile's connectivity without side effects.

## Acceptance

- Reason-code explanation works offline from bundled reference data; unknown
  codes degrade to a documented generic answer, not an error.
- The connectivity check requires only `inspect`, performs no mutation, and
  reports endpoint reachability, identity match, and latency.
- A connectivity failure produces a typed cause (DNS, TLS, authentication,
  authorization, timeout) without leaking credentials.
- Unit tests cover the code table; e2e covers a healthy and an unreachable
  profile.
