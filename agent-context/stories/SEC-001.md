# SEC-001 — Secure remote MCP transport and hardening

**Status:** Blocked by deployment decisions  
**Authority:** `openspec/changes/remote-access-and-operability/proposal.md`

## Outcome

Remote clients are authenticated and authorized independently from downstream
MQ credentials, and the transport enforces abuse limits.

## Acceptance

- stdio trust assumptions and remote HTTP authorization are documented.
- Remote authorization follows the approved MCP specification without token
  passthrough.
- Client identity cannot select or override downstream credentials.
- Rate limits, timeouts, request size limits, and concurrency bounds apply.
- Security tests cover confused-deputy, SSRF/config injection, secret
  leakage, oversized payloads, and unauthorized profile access.
- The audit trail is [SEC-002](SEC-002.md); observability is
  [OBS-001](OBS-001.md).
