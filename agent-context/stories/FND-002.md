# FND-002 — Enforce CI quality gates and supply-chain checks

**Status:** Open; split from FND-001  
**Authority:** `openspec/changes/bootstrap-mq-mcp/proposal.md`

## Outcome

Every change is blocked from merging unless formatting, static analysis,
race-enabled unit tests, vulnerability checks, and secret scanning pass.

## Acceptance

- CI runs formatting, linting, static analysis, `go vet`-class checks,
  race-enabled unit tests, and vulnerability scanning on every pull request.
- Secret scanning and automated dependency updates are active on the
  repository.
- A deliberately failing check demonstrably blocks merge; evidence recorded.
- The exact commands are documented once (AGENTS.md) and referenced elsewhere.
- A local one-command equivalent of the CI gate exists for contributors.
