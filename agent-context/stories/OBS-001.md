# OBS-001 — Health, readiness, metrics, and structured logs

**Status:** Done · Integrated to `main` @ 7f1c256  
**Authority:** `openspec/changes/remote-access-and-operability/proposal.md`

## Outcome

Operators observe server health, per-profile activity, and policy denials
without reading code or enabling debug output.

## Acceptance

- Health and readiness reflect configuration validity and transport state
  without contacting queue managers on every probe.
- Prometheus metrics cover request counts, latency, and policy denials per
  profile with no secret or high-cardinality labels.
- Logs are structured, redacted centrally, and resistant to log injection
  from tool arguments.
- Operational endpoints bind separately from the MCP transport and are absent
  in stdio-only mode.
