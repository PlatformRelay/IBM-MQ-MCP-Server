# POL-001 — Enforce per-profile capabilities

**Status:** Blocked by ADR-0003  
**Authority:** `openspec/changes/connection-profiles-and-policy/proposal.md`

## Outcome

Every operation is authorized against explicit capabilities for the selected
profile before secrets are resolved or IBM MQ is contacted.

## Acceptance

- Capabilities distinguish inspection, browsing, consuming, producing,
  administration, and exceptional raw execution.
- Missing grants deny by default with an actionable non-secret error.
- Tool discovery does not falsely imply that a profile permits an operation.
- Denied-operation tests prove no downstream adapter call occurs.
- Policy decisions are emitted as events; recording them is owned by
  [SEC-002](SEC-002.md), not duplicated here.
- Object-name constraints are split into [POL-002](POL-002.md).

## Open decisions

- Exact read-only/write-only semantics (ADR-0003).
- Whether tools are globally listed or dynamically exposed.
