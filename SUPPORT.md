# Support

## Where to get help

| Need | Channel |
| --- | --- |
| Bug report | [GitHub Issues](https://github.com/PlatformRelay/IBM-MQ-MCP-Server/issues) using the bug template |
| Feature idea | [GitHub Issues](https://github.com/PlatformRelay/IBM-MQ-MCP-Server/issues) using the feature template |
| Security vulnerability | Private disclosure only — see [SECURITY.md](SECURITY.md) |
| Contributing | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Project decisions | [GOVERNANCE.md](GOVERNANCE.md) and [docs/adr/](docs/adr/) |

There is no separate support SLA. The maintainer triages issues as capacity
allows. For usage questions, prefer a well-scoped issue with reproduction steps
and redacted configuration (no secrets).

- Published site (once Pages is enabled): GitHub Pages for this repository
